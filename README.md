# Unwrap

**Stop renting what you can own.**

🌐 **[Visit the Website →](https://xcqtnr.github.io/unwrap/unwrap-ai/docs/)**

## The Problem

The AI boom has created a new category of products: services that provide access to AI models (like GPT-4 or Claude) through a custom interface, often at a significant markup.

Some of these services add genuine value — specialized workflows, fine-tuned models, or unique features. But many are simply reselling API access with a different logo.

The challenge? Most users can't tell the difference. Someone looking for a "PDF analyzer" might pay $20/month without realizing they could do the same thing directly with ChatGPT or NotebookLM for free.

## Our Vision

We believe in an informed market.

When users can easily compare what they're paying for versus what's freely available, two things happen:

1. **Users save money** on services that don't add real value
2. **Creators are encouraged** to build genuinely differentiated products

We're not against paid AI tools. We're against opacity. If a service adds real value, users should choose it knowing the alternatives. If it doesn't, users deserve to know that too.

## What Unwrap Does

**Unwrap AI** is a browser extension that helps you make informed decisions about AI services:

- Identifies when you're visiting a site that may be reselling AI capabilities
- Shows you free or lower-cost alternatives that offer similar functionality
- Provides ready-to-use prompts so you can try the alternative yourself
- Tracks how much you've saved over time

We rely on a community-maintained database. We're not making definitive claims — we're providing information so you can decide for yourself.
